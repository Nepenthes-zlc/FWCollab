# Benchmark readiness

## 已具备

- 24 张公开开发地图，严格解析且结构指纹唯一。
- 每个移动动作只执行一格；F/W 同轮冻结观察、并行提交、独立历史。
- 完整动态地图与不可覆盖静态层；消息固定延迟一轮。
- 24 个私有单步成功见证、逐轮状态哈希与确定性回放。
- 离线策略和显式启用的 OpenAI-compatible 双 LLM runner。
- 模型错误容错、最大轮数、过程指标和交互式 HTML 回放。
- 生成器产物带私有成功证书；套件级 ID/结构去重。

## 仍不应声称

- S01–S24 是公开开发集，不是 held-out 测试集。
- `comparison_reference` 只表示机制比较参照；因为布局也有变化，不是受控单变量反事实。
- 72个私有参考DAG已经使用结构化状态谓词、双层比较和无环/可达/唯一性校验；当前仍是空间落地前的抽象结构，尚未绑定到新生成地图的replay实际状态。
- 一个成功见证不证明最优性、解唯一性、交流必要性或合作必要性。
- 难度数字是暂定作者标签，尚未经过多模型、多随机种子实验校准。
- 目前没有独立地图设计者或外部人工评测审核。

这些项目属于 `S05-02` 发布门禁；补齐前可以做开发实验，但报告中必须明确称为 prototype/development benchmark。
